# Public content

- Refer to validation projects by their designated product codes, such as
  `SLUS-00614` or `RTRE18`, throughout filenames, documentation, commits, pull
  requests and comments. Omit game titles from project-specific examples.
- Exclude private infrastructure identifiers, hostnames, network addresses,
  deployment topology and environment-specific filesystem paths from public
  content. Use generic placeholders when an example needs a path or endpoint.
- Keep validation reports focused on behavior, checks and results. Do not publish
  game images, generated game source, credentials or private operational details.
