# hardware.inc 6.0.0

`hardware.inc` and `hardware_compat.inc` are [gbdev/hardware.inc](https://github.com/gbdev/hardware.inc) v6.0.0,
unchanged: the Game Boy community's names for the hardware registers, the cartridge mapper's registers, memory areas
and their bits. Public domain (CC0 1.0, as each file says).

decomp.wtf names registers in Game Boy listings with them (rom/gb_hw.py), and documented assembly is assembled with
both included, so the names of 6.0 and the older ones `hardware_compat.inc` keeps both work.
